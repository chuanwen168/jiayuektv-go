# 家悦K歌 · 局域网家庭 KTV 点歌系统

> 在家里的电视 / 平板 / 手机上点歌唱 K 的局域网系统。
> **一台电脑或 NAS 当服务器**，全家用手机扫码点歌、平板当点歌台、电视大屏播放，歌库放在硬盘里自己说了算。

---

## 一、它是什么？

一套跑在你自用设备上的 KTV 系统，包含 4 个页面：

| 页面 | 用途 | 谁用 |
| --- | --- | --- |
| 🖥 **TV 播放端** | 大屏放歌（原唱/伴唱切换、切歌、音量、均衡器、滚动字幕、待机大屏） | 电视（网页版 `/tv/` **或** 安卓 TV 原生 App） |
| 📟 **PAD 点歌台** | 触屏点歌、置顶/删除、歌手/语种/风格分类 | 包房平板 |
| 📱 **手机点歌** | 拼音搜索、歌手点歌、分类点歌、互动 | 全家手机 |
| ⚙ **曲库管理** | 扫描曲库、改语种/风格、批量设置、改密码 | 管理员 |

主要特性：

- ✅ **局域网零外网**：所有页面、视频、点歌全部内网传输，不依赖公网
- ✅ **多音轨**：歌曲带"原唱+伴唱"双音轨，电视端一键切换（原/伴唱）
- ✅ **硬件加速转码**：Intel/AMD 核显（VAAPI）自动硬解硬编，CPU 占用低；H.265/AV1 视频自动转成电视能播的 H.264
- ✅ **多歌手识别**：`歌手1&歌手2 - 歌名` 自动拆成两个歌手
- ✅ **语种 / 风格**：国语/粤语/英语/日语/韩语… 流行/摇滚/怀旧/儿歌… 后台随意改
- ✅ **歌手头像**：放一张 `歌手名.jpg`，三端自动展示，没有头像自动用首字母色块
- ✅ **安卓预留接口**：已提供 HTTP 接口，后续可对接安卓 TV 原生 App

## 二、开始之前

| 需要准备 | 说明 |
| --- | --- |
| 一台常开的设备 | **方案 A：Windows 电脑**（最简单，适合先体验）；**方案 B：飞牛 NAS / 任何 Linux 服务器**（推荐长期用） |

## 三、方案 A：Windows 电脑上跑（最快体验）

1. 到 **[Release 下载页](https://github.com/chuanwen168/jiayuektv-go/releases)** 下载 ktvhome-windows.zip，解压到任意目录（如 D:\jiayuektv）
2. 在解压目录里新建 `mv` 文件夹，把你的歌曲文件放进去（也可以建子文件夹分类）
   ```
   D:\jiayuektv\mv\中文歌\...
   D:\jiayuektv\mv\英文歌\...
   ```
3. **需要 ffmpeg**：下载 ffmpeg（Windows 版，选 essentials 即可），把里面的 `ffmpeg.exe` 和 `ffprobe.exe` 放到项目根目录（和 `ktv-server.exe` 同一个文件夹）
4. 双击 **`start.bat`**，出现黑色窗口显示 `KTV 服务已启动` 就成功了（窗口别关）
5. 打开浏览器访问：**http://127.0.0.1:8080**
   - TV 播放端：http://127.0.0.1:8080/tv/
   - PAD 点歌台：http://127.0.0.1:8080/pad/
   - 手机点歌：http://127.0.0.1:8080/m/
   - 曲库管理：http://127.0.0.1:8080/admin/ （默认密码 `admin888`，请尽快修改）
6. 第一次进后台，点右上角 **🔄 扫描曲库**，歌就进来了

> 📱 手机点歌：同一 WiFi 下手机访问 `http://电脑IP:8080/m/`，把电脑 IP 换成你电脑的局域网 IP（`ipconfig` 查看）。

## 四、方案 B：飞牛 NAS / Linux 服务器部署（推荐长期用）

> 🐟 **飞牛（fnOS，x86）用户请以 [README-fnos.md](README-fnos.md) 为准**——飞牛专属的完整部署/升级/故障排查指南（含目录挂载、核显直通、端口说明）。本段为通用 Linux 步骤，两者按需取用。

### 方式一（推荐）：直接拉取镜像，复制即用（无需下载上传项目）

SSH 登录 NAS 后执行：

```bash
mkdir -p /vol1/1000/docker/ktvhome && cd /vol1/1000/docker/ktvhome
mkdir -p data mv singer
nano docker-compose.yml
```

把下面内容粘贴保存为 `docker-compose.yml`：

```yaml
services:
  jiayue-ktv:
    image: ghcr.io/chuanwen168/jiayuektv-go:1.0.2   # 想永远用最新版可改成 :latest
    container_name: jiayue-ktv
    restart: unless-stopped
    ports:
      - "8086:8080"          # 访问端口：http://局域网IP:8086
    environment:
      - TZ=Asia/Shanghai
      - PORT=8080
      - DATA_DIR=/data
      - ADMIN_PASSWORD=admin888          # 管理后台("/admin")登录密码，建议改掉
      - VAAPI_DEVICE=/dev/dri/renderD128 # 核显硬件转码用，没有核显就删掉这行
      - HLS_CACHE_MAX_AGE_DAYS=3         # 转码缓存超过几天没人点就自动清理
    volumes:
      - ./data:/data                 # 应用数据(数据库、封面等)，必须挂载
      # 曲库挂载：本地曲库挂到 /mv/<自定义名>，网盘曲库挂到 /mv-net/<自定义名>
      - ./mv:/mv/library1            # 把歌曲放进 ./mv 目录（可建子文件夹分类）
      - ./singer:/singer             # 歌手头像目录，图片名对应歌手名，如 周杰伦.jpg
      # 挂载完成后，还需要去后台「曲库管理→曲库来源」里把新目录逐个启用，才会真正参与扫描
    devices:
      - /dev/dri:/dev/dri            # 核显硬件转码用，没有核显就删掉这行
```

启动：

```bash
sudo docker compose up -d
```

> 以后服务端更新：`sudo docker compose pull && sudo docker compose up -d`，数据库和曲库（`./data`、`./mv`）不受影响。

### 方式二（从 Release 安装包部署）
### 第 1 步：到 [Release 下载页](https://github.com/chuanwen168/jiayuektv-go/releases) 下载对应版本项目 zip 包（x86 飞牛选 ktvhome-linux-amd64.zip），把项目包上传到 NAS

用飞牛的文件管理或 SCP 把项目解压到 NAS 磁盘，举例路径：

```
/vol1/1000/docker/ktvhome
```

（`/vol1` 是你的存储卷名，按实际情况修改）

### 第 2 步：SSH 登录 NAS

飞牛开启 SSH（设置 → 终端 / SSH），电脑上用终端连上：

```bash
ssh admin@你的飞牛IP
```

### 第 3 步：准备目录（路径根据你的实际修改）

```bash
cd /vol1/1000/docker/ktvhome
mkdir -p data mv mv-net singer
```

- `mv/` 放本地歌曲（每个子文件夹一个曲库，如 `mv/华语`、`mv/英文`）
- `mv-net/` 放网盘挂载的歌曲（可选）
- `singer/` 放歌手头像（图片名 = 歌手名，如 `周杰伦.jpg`）

### 第 4 步：构建并启动

```bash
sudo docker compose -f docker-compose.fnos.yml up -d --build
```

> ⚠️ **如果你的 NAS 没有核显/独显**：先编辑 `docker-compose.fnos.yml`，把 `devices:` 那几行删掉，再执行上面的命令。

等几分钟，看是否启动成功：

```bash
sudo docker logs -f jiayue-ktv-go
```

看到 `KTV 服务已启动` 即可。**再确认一下硬件加速**：日志里有 `核显调用: 成功` 说明核显转码生效（CPU 占用低）；如果是 `未检测到渲染节点`，说明在走软件编码（CPU 占用高），检查第 4 步的 devices 是否被删。

### 第 5 步：开始使用

浏览器访问 **http://你的飞牛IP:8086**

| 页面 | 地址 |
| --- | --- |
| 主页（四个入口） | `http://飞牛IP:8086/` |
| TV 播放端 | `http://飞牛IP:8086/tv/` |
| PAD 点歌台 | `http://飞牛IP:8086/pad/` |
| 手机点歌 | `http://飞牛IP:8086/m/` |
| 曲库管理 | `http://飞牛IP:8086/admin/`（默认密码 `admin888`，**建议立即修改**） |

首次使用：进后台 → **🔄 扫描曲库**。

## 五、TV 端介绍（大屏播放）

家悦K歌有两个 TV 播放端，功能一致、二选一即可：

### 1️⃣ 网页版 TV 播放端（浏览器打开 `/tv/`）

适合**有浏览器/带遥控器网页功能的电视、盒子**，或电脑大屏预览：

- **待机大屏**：未点歌或切完最后一首时，显示"家悦K歌"渐变 Logo + "播放端已就绪"，点歌后自动开播
- **顶部滚动字幕**：KTV 风格，从屏幕最右滚到最左，10~20 秒出现一次；先播报"正在播放 / 下一曲"，再滚动后台设置的欢迎语（后台可改）
- **控制按钮**：暂停、原/伴唱、重唱、切歌、音量±、均衡器（10 段）、全屏
- **已点列表**：右侧窄列实时显示队列，正在播放的歌曲高亮
- **全屏模式**：隐藏列表与控制条，画面纯净
- **多音轨**：原唱/伴唱一键切换（需歌曲本身是双音轨）
- 播放降级链：hls.js → 原生 HLS → 直连视频流，黑屏/转圈自动恢复

### 2️⃣ 安卓 TV 原生客户端（`jiayuektv-tv-1.0.2.apk`）

适合**安卓电视 / 电视盒子**（Android 6.0 及以上），原生全屏播放、遥控器操作：

- **原生全屏播放**：ExoPlayer 内核，AV1/H.265/H.264 通吃（H.265/AV1 由服务端自动转码成电视可播的 H.264；硬解失败自动回退软解）
- **待机大屏**：与网页版同款"家悦K歌"渐变 Logo，未点歌 / 切完最后一首自动显示
- **滚动字幕**：与网页版一致的"歌曲播报 + 欢迎语"两段式滚动
- **悬浮控制栏**：暂停、重唱、切歌、音量±、原/伴唱、扫码、设置；无操作 5 秒自动隐藏，点击屏幕唤出
- **扫码**：点击弹出右上角二维码，手机扫码直接打开点歌页（再点一次关闭）
- **设置页**（遥控器「菜单」键或设置按钮）：
  - 服务器地址（IP:端口，如 `192.168.1.100:8086`）
  - **播完随机播放**：开关，默认关闭；开启后播完自动随机续播
  - **切歌默认请求**：伴唱 / 原唱 / 上次（沿用上一首，上一首未指定则默认伴奏）
- **遥控器适配**：方向键唤出控制层、返回键二次确认退出、菜单键开设置
- 播完自动切下一首（按"播完随机播放"设置决定是否随机续播）

## 六、日常使用

### 点歌流程

1. 电视打开 **TV 播放端**（全屏显示"请点歌"待机画面）
2. 手机 / 平板打开点歌页，搜歌、点歌
3. 歌曲自动进入电视队列播放，电视端可切原/伴唱、切歌、调音量

### 语种 / 风格管理

后台曲库管理表格里，每首歌可直接下拉改语种/风格；勾选多首可**批量设置**；预设项可增删（语种：国语/粤语/英语/日语/韩语/其他；风格：流行/摇滚/怀旧/儿歌等）。

### 歌手头像

往 `singer/` 放 `歌手名.jpg`（多歌手：`周杰伦&林俊杰.jpg`），重启或下次扫描后三端自动展示。

## 七、常见问题（FAQ）

**Q：后台密码是什么？**
默认 `admin888`（仅首次未设密码时生效）。登录后右上角「🔑 修改密码」改掉。设置过密码后，compose 里的 `ADMIN_PASSWORD` 不再生效，以后台改的为准。

**Q：扫不到歌曲？**
① 检查歌曲目录是否挂载/放对位置（Windows 看 `mv` 文件夹、NAS 看 `mv/` 挂载）；② NAS 上新挂的曲库需要进后台「曲库管理 → 曲库来源」把来源**启用**；③ 点右上角「🔄 扫描曲库」。

**Q：电视上黑屏不播放 / 转圈？**
页面会自动降级（hls.js → 原生 HLS → 直连视频源），一般能自动恢复；确认歌曲文件本身完整可播。

**Q：切不了原唱/伴唱？**
需要歌曲本身是双音轨（原唱+伴唱）。单音轨歌曲没有伴唱，切不了是正常的。

**Q：CPU 占用高？**
多半是硬件加速没生效：检查日志是否 `核显调用: 成功`，NAS 上确认 `docker inspect jiayue-ktv-go` 里能看到 `/dev/dri` 设备。

**Q：想换端口？**
改 `docker-compose.fnos.yml` 里 `ports` 左侧的数字（如 `8085:8080`），再重新 `up -d --build`。

**Q：怎么升级？**
替换新版本文件后重新执行启动命令即可，数据库（`data/`）和曲库不受影响：
```bash
sudo docker compose -f docker-compose.fnos.yml up -d --build
```

## 八、技术信息（给折腾党）

- 语言：**Go**（服务端，静态编译单文件）+ 原生 Web 前端（无需 Node 构建）
- 数据库：SQLite（单文件 `data/ktv.db`）
- 转码链：VAAPI 硬解硬编 → NVENC → libx264 软件兜底；H.265/AV1 自动转 H.264 兼容电视
- 播放：HLS 切片（master.m3u8 带原唱/伴唱音轨）+ 三级降级
- 部署：Docker（`Dockerfile` 多阶段 / `Dockerfile.single` 单阶段含预编译二进制），飞牛详见 `README-fnos.md`
