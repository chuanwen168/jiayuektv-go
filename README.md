# 家悦K歌 · 局域网家庭 KTV 点歌系统

> 在家里的电视 / 平板 / 手机上点歌唱 K 的局域网系统。
> **一台电脑或 NAS 当服务器**，全家用手机扫码点歌、平板当点歌台、电视大屏播放，歌库放在硬盘里自己说了算。

当前版本：**v1.1.2**
项目地址：<https://github.com/chuanwen168/jiayuektv-go>

> 本项目不再提供 zip 免安装包，统一使用 **飞牛 FPK** 或 **Docker 镜像** 部署。

---

## 一、它是什么？

一套可以跑在个人设备上的 KTV 系统，包含 4 个页面和 2 个安卓 TV 客户端：

| 页面 | 用途 | 谁用 |
| --- | --- | --- |
| 🖥 **TV 播放端** | 大屏放歌（原唱/伴唱切换、切歌、音量、均衡器、滚动字幕、待机大屏） | 电视、投影仪（网页版 `/tv/` 或 安卓 TV 原生 App） |
| 📟 **PAD 点歌台** | 触屏点歌、置顶/删除、歌手/语种/风格分类 | 包房固定平板、点歌屏 |
| 📱 **手机点歌** | 拼音搜索、歌手点歌、分类点歌、氛围互动 | 局域网内所有手机 |
| ⚙ **管理后台** | 扫描曲库、改语种/风格、批量设置、多房间管理、改密码 | 管理员 |

主要特性：

- ✅ **局域网零外网**：页面、视频、点歌全部在内网传输，不依赖公网
- ✅ **多房间管理（v1.1.2）**：一台服务器可服务多个包房/房间，每个房间独立队列、独立播放状态
- ✅ **独立切换密码（v1.1.2）**：切房间只需“切换密码”（默认 `8888`），不再需要管理员密码；房间增删、设备换绑等数据操作仍只允许管理员
- ✅ **多音轨**：歌曲带“原唱 + 伴唱”双音轨，电视端一键切换（原/伴唱）
- ✅ **硬件加速转码**：Intel/AMD 核显（VAAPI）自动硬解硬编，CPU 占用低；H.265/AV1 等不支持的视频自动转成电视能播的 H.264
- ✅ **转码并发自适应**：弱机按 CPU 线程数限制，强机适度放宽（最高 15 路），多房间同时切歌不卡死
- ✅ **多歌手识别**：`歌手1&歌手2 - 歌名` 自动拆成两个歌手
- ✅ **语种 / 风格**：国语/粤语/英语/日语/韩语… 流行/摇滚/怀旧/儿歌… 后台随意改
- ✅ **歌手头像**：放一张 `歌手名.jpg`，三端自动展示，没有头像自动用首字母色块
- ✅ **氛围互动**：手机端欢呼/鼓掌/尖叫/口哨/喝倒彩/再来一首，TV 端实时音效 + 浮层
- ✅ **安卓 TV 原生客户端**：Media3 播放内核，直连 / HLS 双模式，遥控器全适配
- ✅ **最低支持安卓 4.4**：迷你版客户端可在老电视、老盒子上跑

## 五、部署方式一：飞牛 FPK（推荐）

1. 到 [GitHub Releases](https://github.com/chuanwen168/jiayuektv-go/releases) 下载对应版本的 `jiayuektv-x86-vX.Y.Z.fpk`；
2. 打开飞牛 NAS 应用中心 → 手动安装 → 选择 FPK 安装包；
3. 安装完成后，在应用中心启动「家悦K歌」；
4. 浏览器访问 `http://飞牛IP:8086`。

首次使用：

- 管理后台：`http://飞牛IP:8086/admin/`，默认密码 `admin888`，登录后请立即修改；
- 进入后台 → 点右上角 🔄 扫描曲库，歌曲就会进入曲库；
- 需要多房间时，进入后台「🏠 多房间管理」开启多房间模式（详见第七节）。

升级：在应用中心用新 FPK 覆盖安装即可；升级前建议备份 `data`（数据库、封面等）与曲库目录。

## 六、部署方式二：Docker

在 Docker 管理页面新建项目，把下面内容保存为 `docker-compose.yml`：

```yaml
services:
  jiayue-ktv:
    image: ccr.ccs.tencentyun.com/chuanwen168/jiayuektv-go:latest
    # 海外网络可改用：ghcr.io/chuanwen168/jiayuektv-go:latest
    container_name: jiayue-ktv
    restart: unless-stopped
    ports:
      - "8086:8080"          # 访问端口：http://局域网IP:8086
    environment:
      - TZ=Asia/Shanghai
      - PORT=8080
      - DATA_DIR=/data
      - ADMIN_PASSWORD=admin888          # 后台登录密码，建议改掉
      - VAAPI_DEVICE=/dev/dri/renderD128 # 核显硬件转码用，没有核显就删掉这行
      - HLS_CACHE_MAX_AGE_DAYS=3         # 转码缓存超过几天没人点就自动清理
    volumes:
      - ./data:/data                     # 应用数据（数据库、封面等），必须挂载
      - ./mv:/mv/library1                # 本地曲库，可建子文件夹分类
      # - ./mv-net:/mv-net/library2      # 网盘挂载曲库（可选）
      - ./singer:/singer                 # 歌手头像，图片名 = 歌手名，如 周杰伦.jpg
    devices:
      - /dev/dri:/dev/dri                # 核显硬件转码用，没有核显就删掉这行
```

启动：

```bash
sudo docker compose up -d
```

升级：

```bash
sudo docker compose pull && sudo docker compose up -d
```

`data/` 与曲库不受影响；需要回滚时把镜像改回旧版本标签再 `up -d` 即可。挂载完成后，还需要去后台「曲库管理 → 曲库来源」把新目录逐个启用，才会真正参与扫描。

## 七、多房间管理（v1.1.2）

一台服务器服务多个包房时使用，单房间家庭可以不开。

**开启方式**

1. 管理后台 →「🏠 多房间管理」→ 打开“多房间模式”；
2. 在「房间管理」里新增/改名/删除房间；
3. 在「设备绑定」里把电视、平板、点歌设备分配到对应房间。

**使用规则**

- 每个房间有独立点歌队列、独立播放状态，互不影响；
- 设备首次连接会自动分配空房间，之后记住绑定关系；
- 安卓 TV 端二维码会自动带上当前房间，扫码地址形如：
  `http://服务器IP:8086/m/?room_id=1`
- 手机扫码后，点歌页顶部显示**房间名称**，不再是房间号；
- PAD / TV 顶部出现房间切换下拉，换房间只需输入**切换密码**（默认 `8888`）；
- 不在二维码入口、直接打开 `/m/` 且没有 `room_id` 时，会被拦截并提示扫码。

**权限说明**

| 操作 | 需要的权限 |
| --- | --- |
| 切换房间 | 房间切换密码（默认 `8888`） |
| 新增/改名/删除房间 | 管理员登录 |
| 修改设备绑定 | 管理员登录 |
| 修改切换密码 | 管理员登录 |

切换密码在「多房间管理」标签页内修改，至少 4 位。它和后台管理员密码是两套独立密码。

## 八、TV 端介绍（大屏播放）

家悦K歌提供两个 TV 播放端，功能一致、二选一即可。

### 1️⃣ 网页版 TV 播放端（浏览器打开 `/tv/`）

适合带浏览器/遥控器网页功能的电视、盒子，或电脑大屏预览：

- 待机大屏：未点歌时显示“家悦K歌”Logo 与“播放端已就绪”
- 顶部滚动字幕：先播报“正在播放 / 下一曲”，再滚动后台设置的欢迎语
- 控制按钮：暂停、原/伴唱、重唱、切歌、音量±、均衡器（10 段）、全屏
- 已点列表：右侧窄列实时显示队列，正在播放的歌曲高亮，可置顶/删除
- 多音轨：原唱/伴唱一键切换（需歌曲本身是双音轨）
- 播放降级链：hls.js → 原生 HLS → `/stream` 直连视频流，黑屏/转圈自动恢复
- 均衡器预设：原声 / 流行 / 摇滚 / 舞曲 / 人声 / DIY，与 PAD 端实时同步

> 网页 TV 默认走 HLS；直连 `/stream` 只作为 HLS 失败时的兜底。浏览器对 H.265/AV1/MKV 支持有限，不建议以直连为主。

### 2️⃣ 安卓 TV 原生客户端（v1.1.2）

适合安卓电视 / 电视盒子（**Android 6.0 及以上**）：

- 原生全屏播放，Media3 播放内核，遥控器方向键 / 返回键 / 菜单键全适配
- 双播放模式：
  - **直连模式**：本地点播原始视频，起播快、延迟低，不占服务器转码资源
  - **HLS 模式**：服务端转码切片，兼容性最强，适合网络抖动或电视解不了的格式
- 点歌瞬间按媒体信息 + 本机解码能力决策：默认直连，不支持的格式/分辨率自动走 HLS，失败自动回退
- 待机大屏：与网页版同款渐变 Logo，未点歌 / 播完最后一首自动显示
- 滚动字幕：歌曲播报 + 欢迎语两段式滚动
- 悬浮控制栏：暂停、重唱、切歌、音量±、原/伴唱、扫码、设置；无操作自动隐藏
- 扫码点歌：二维码自动携带当前房间号，手机扫码直接进入对应房间
- 下一首预转码：**HLS 模式**下当前歌曲播放超过 30 秒，自动预热下一首，切歌更快
- 设置页：服务器地址、播放模式、播完随机播放、切歌默认请求
- 远程控制：手机端暂停/播放/切歌与遥控器完全一致

### 安卓 4.4 迷你版客户端（v1.1.1）

- 最低 **Android 4.4**，兼容老旧电视和盒子
- ExoPlayer 内核，仅支持 HLS 模式（不支持直连）
- 保留扫码点歌、遥控器操作、滚动字幕等核心功能

## 九、日常使用

### 点歌流程

1. 电视打开 TV 播放端，显示待机画面；
2. 手机 / 平板扫码或打开点歌页，搜歌、点歌；
3. 歌曲自动进入对应房间队列播放；
4. 电视端可切原/伴唱、切歌、调音量，手机端也可远程控制。

### 氛围互动

手机点歌页下方互动区，可发送 **欢呼 / 鼓掌 / 尖叫 / 口哨 / 喝倒彩 / 再来一首**，TV 端实时播放对应音效并显示浮层动画。

### 语种 / 风格管理

后台曲库管理表格里，每首歌可直接下拉改语种/风格；勾选多首可批量设置；预设项可增删。

### 歌手头像

往 `singer/` 放 `歌手名.jpg`（多歌手：`周杰伦&林俊杰.jpg`），重启或下次扫描后三端自动展示。

## 十、常见问题（FAQ）

**Q：后台密码是什么？**
默认 `admin888`（仅首次未设密码时生效）。登录后点右上角 🔑 修改密码。设置过密码后，环境变量 `ADMIN_PASSWORD` 不再生效。

**Q：多房间的切换密码是什么？**
默认 `8888`，在后台「🏠 多房间管理」标签页修改。它和管理员密码独立；切房间不需要管理员密码。

**Q：普通用户能改房间数据吗？**
不能。新增/改名/删除房间、修改设备绑定、修改切换密码都需要管理员登录；普通用户只能凭切换密码换房间。

**Q：多房间模式下直接打开 `/m/` 提示扫码？**
正常。多房间模式要求手机入口携带 `room_id`，请通过 TV 端二维码进入，或手动访问 `/m/?room_id=1`。

**Q：扫不到歌曲？**
① 检查歌曲目录是否挂载/放对位置；② 新挂载的曲库需要进后台「曲库管理 → 曲库来源」启用；③ 点右上角「🔄 扫描曲库」。

**Q：电视上黑屏不播放 / 转圈？**
网页版会自动降级（hls.js → 原生 HLS → `/stream`）；安卓 TV 默认直连，检测到不支持会自动回退 HLS。确认歌曲文件本身完整可播。

**Q：切不了原唱/伴唱？**
需要歌曲本身是双音轨（原唱 + 伴唱）。单音轨歌曲切不了是正常的。

**Q：CPU 占用高？**
多半是硬件加速没生效：查看日志是否出现“核显调用: 成功”；NAS/Docker 上确认能看到 `/dev/dri` 设备。没有核显会自动使用软件编码。

**Q：想换端口？**
Docker 改 compose 里 `ports` 左侧数字，如 `8085:8080`，再 `up -d`；FPK 安装时按应用中心分配的端口访问。

**Q：怎么升级？**
FPK：应用中心用新包覆盖安装；Docker：`sudo docker compose pull && sudo docker compose up -d`。升级前备份 `data/` 。

## 十一、技术信息（给折腾党）

- **语言**：Go（服务端，静态编译单文件）+ 原生 Web 前端。运行效率优于解释型语言。
- **数据库**：SQLite（单文件 `data/ktv.db`）
- **转码链**：VAAPI 硬解硬编 → NVENC → libx264 软件兜底；H.265/AV1 自动转 H.264
- **转码并发**：≤8 线程按线程数；>8 线程适度超配 1.25 倍，最高 15 路；HLS 转码与直连多音轨共用同一信号量
- **播放**：HLS 切片（`master.m3u8` 带原唱/伴唱音轨）+ 直连视频流（`/stream`）；安卓 TV 客户端直连 / HLS 双模式
- **实时通信**：WebSocket（`/ws`）广播点歌、氛围互动、播放状态；多房间按 `room_id` 隔离
- **部署**：飞牛 FPK（约 10MB，调用系统 ffmpeg）+ Docker 镜像（amd64 / arm64）
- **镜像**：`ghcr.io/chuanwen168/jiayuektv-go`（海外）与 `ccr.ccs.tencentyun.com/chuanwen168/jiayuektv-go`（国内）
